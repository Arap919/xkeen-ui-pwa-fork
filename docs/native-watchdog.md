# Встроенный Watchdog

Реализация подготовлена в ветке `feature/native-watchdog`. Установка на роутер ещё не выполнена.

Управление: шестерёнка в верхней панели → вкладка Watchdog. Автоматический режим включён по умолчанию. Переключатель сохраняется отдельно от черновика настроек; параметры применяются кнопкой «Сохранить». Пустое поле секрета сохраняет существующий секрет, удаление выполняется отдельным переключателем при сохранении.

Планировщик работает внутри процесса панели. При остановке панели проверки прекращаются. Выключение режима отменяет текущую автоматическую задачу; выбранный узел сохраняется. Ручные операции CLI используют общую блокировку.

При первом запуске на роутере панель удаляет прежние watchdog-задания из cron и ежеминутный hook, заменяет `/opt/bin/router-watchdog` адаптером к `/opt/sbin/xkeen-ui watchdog`. Python-скрипт больше не вызывается. Старые файлы Python автоматически не удаляются. Cron нужен только для удаления прежних заданий и перезапуска cron после миграции; дальнейшее расписание выполняет панель. Ошибка миграции блокирует запуск новой автоматической проверки и повторяется на следующем проходе. Возврат к Python-движку не предусмотрен.

Конфигурация сохраняется в `/opt/etc/router-watchdog.json`; состояние включения — `watchdog.enabled` в `/opt/etc/xkeen/xkeen-ui.json`. Движок обновляется вместе с панелью. CLI `--sync-cron` и `--remove-cron` очищают прежние задания; расписание перечитывается встроенным планировщиком каждую минуту.

Скрытая вкладка браузера закрывает connections WebSocket и приостанавливает опрос system/control. При возвращении соединение и опрос восстанавливаются. Backend объединяет одновременные запросы статуса и кеширует успешный ответ на 2 секунды, ошибку на 500 мс.

## Установка после согласования

Перед установкой требуется согласовать готовый бинарник. Затем штатно заменить бинарник панели и перезапустить её; при первом запуске произойдёт описанная миграция. Проверить вкладку Watchdog, состояние cron, журнал `/opt/share/router-watchdog.log` и отсутствие Python-процессов watchdog. Публикация и установка не выполняются автоматически.
